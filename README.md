# MouseFaceTrack

MouseFacetrack ist ein Python-Projekt, das den Mauszeiger mithilfe einer Webcam und Gesichtserkennung steuert. Das Ziel ist es, den Computer freihändig bedienen zu können, indem Kopfbewegungen und Gesichtsgesten in Mausaktionen umgesetzt werden.

## Funktionen

- Steuerung des Mauszeigers durch Kopfbewegungen
- Echtzeit-Gesichtserkennung mit der Webcam
- Freihändige Bedienung des Computers
- Unterstützung für Menschen mit eingeschränkter Mobilität
- Einfache und benutzerfreundliche Nutzung

## Verwendete Technologien

- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## Installation

1. Repository klonen:

```bash
git clone https://github.com/DEIN-BENUTZERNAME/MouseFacetrack.git
```

2. Benötigte Bibliotheken installieren:

```bash
pip install opencv-python mediapipe pyautogui
```

## Verwendung

Starte das Programm mit:

```bash
python gesichtmaus.py
```

Danach wird die Webcam aktiviert und die Gesichtserkennung gestartet. Durch Bewegungen des Kopfes kann der Mauszeiger gesteuert werden.

## Ziel des Projekts

Dieses Projekt wurde entwickelt, um alternative Eingabemethoden für Computer zu erforschen und die Barrierefreiheit digitaler Geräte zu verbessern.
